# Pianoverse Player (local songs) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A React web app in `app/` with a song library and a landscape player that loads engine `song.json` files from `public/songs/`, shows falling notes on a canvas with a lit keyboard, plays them with a sampled piano, and offers level / hands / speed / A–B loop / note names / chord card — in Greek and English, styled as the approved "Α · Σκηνή" mockup.

**Architecture:** Vite + React + TypeScript. Pure, unit-tested modules do all the maths (keyboard layout, note rectangles, chord timeline, transport/loop clock, which notes to sound). Thin React components and one canvas renderer sit on top. A single `PlaybackClock` (our own transport over `performance.now()`) is the time source; the canvas reads `clock.now()` every frame and a piano engine triggers Tone.js sampler notes when the clock crosses them. UI state lives in small Zustand stores; all copy comes from typed `el`/`en` message objects.

**Tech Stack:** Node ≥ 20, pnpm, Vite, React 19, TypeScript (strict), react-router 7, Zustand 5, Tone.js 15 (Salamander piano samples), Vitest + Testing Library + jsdom, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-07-pianoverse-design.md` — §4.1 (Song JSON), §5 (app), §6 (visual, chosen direction «Α · Σκηνή»), §6.1 (i18n), §8 (testing), §9 step 3. Mockups: https://claude.ai/artifact/DbK1P2a9X7r5Y6u183dZHz

## Global Constraints

- All app commands run from `app/`; package manager `pnpm` (never npm or npx); Node ≥ 20.
- TypeScript `strict`, `verbatimModuleSyntax` (type-only imports use `import type`), no `enum`s, no constructor parameter properties.
- Song contract: `schema/song.schema.json`, `schemaVersion: 1`; levels `easy | medium | hard | original`; hands `"L" | "R"`; times in seconds.
- Every user-visible string comes from `src/i18n/messages.ts` (`el` and `en`); exceptions: the brand name "Pianoverse", "BPM", the language labels "ΕΛ"/"EN", chord symbols.
- Note names follow the language: `el` → Ντο Ρε Μι Φα Σολ Λα Σι, `en` → C D E F G A B. Chord symbols stay international (Am, F, G7, C/E).
- Colours and fonts are defined once in `src/styles/theme.ts` (values from spec §6): bg `#0A0C14`, surface `#141927`, line `#242B3E`, text `#EEF1F8`, muted `#97A0B8`, left hand `#4D8DFF`, right hand / accent `#FFA94D`; Space Grotesk (display), Inter (body), JetBrains Mono (labels). CSS reads them as variables.
- Touch targets ≥ 44 px; icon-only buttons have `aria-label`; icons are inline SVG with `aria-hidden="true"`; no emoji.
- Fast tests (`pnpm test`) never load Tone.js, never touch the network, and their output is pristine.
- No audio files are committed; the demo song is generated by a script.

### Rulings against the spec (recorded here so reviewers judge them as requirements)

- **Clock:** spec §5.3 names Tone.Transport as the master clock for "piano" mode. This plan uses its own `TransportClock` (pure, unit-testable, handles rate and A–B loop) and triggers the Tone sampler from it. Same user-visible behaviour; testable without audio.
- **Audio modes "original" and "mix"** (spec §5.3 items 2–3) need the song's audio, which only arrives with the backend (spec §9 step 4). They are out of scope here; this plan ships "piano" mode only.
- **Song types** are hand-written in `src/song/types.ts`, with a test that fails when `schema/song.schema.json` changes, instead of a code generator (pydantic's tuple output for `timeSignature` doesn't convert cleanly).
- **Metronome with count-in** and the **list of all the song's chords** (spec §5.2) are deferred to the next player plan, to keep this one shippable; the chord card for the current chord is in.
- **Particles/ripple on key press** and **Framer Motion transitions** (spec §6) are deferred to the next player plan; this one lights the pressed keys and has no animated transitions.
- **TanStack Query** (spec §5.4) is deferred to the next player plan; the app reads two static JSON files with `fetch` today, so it brings no caching or retry win yet.
- **Keyboard octave labels** stay international (C2–C8) in both languages, like chord symbols; note names under the falling notes and in the chord card are localised.

`app/src/i18n/lang.ts`:

```ts
import { create } from 'zustand'
import { messages, type Lang, type Messages } from './messages'

export type { Lang } from './messages'

export const LANG_KEY = 'pianoverse.lang'

export function detectLang(navigatorLanguage: string | undefined): Lang {
  return navigatorLanguage?.toLowerCase().startsWith('el') ? 'el' : 'en'
}

export function initialLang(): Lang {
  try {
    const saved = localStorage.getItem(LANG_KEY)
    if (saved === 'el' || saved === 'en') return saved
  } catch {
    // storage blocked: fall back to the device language
  }
  return detectLang(typeof navigator === 'undefined' ? undefined : navigator.language)
}

interface LangState {
  lang: Lang
  setLang: (lang: Lang) => void
}

export const useLang = create<LangState>((set) => ({
  lang: initialLang(),
  setLang: (lang) => {
    try {
      localStorage.setItem(LANG_KEY, lang)
    } catch {
      // storage blocked: the choice lasts for this session only
    }
    document.documentElement.lang = lang
    set({ lang })
  },
}))

export function useMessages(): Messages {
  return messages[useLang((s) => s.lang)]
}
```

export const QUALITY_INTERVALS: Record<string, number[]> = {
  maj: [0, 4, 7], min: [0, 3, 7], '7': [0, 4, 7, 10], maj7: [0, 4, 7, 11], m7: [0, 3, 7, 10],
  sus2: [0, 2, 7], sus4: [0, 5, 7], dim: [0, 3, 6], aug: [0, 4, 8],
}

const QUALITY_LONG: Record<Lang, Record<string, string>> = {
  el: {
    maj: 'μείζονα', min: 'ελάσσονα', '7': 'με 7η', maj7: 'μείζονα με μεγάλη 7η', m7: 'ελάσσονα με 7η',
    sus2: 'sus2', sus4: 'sus4', dim: 'ελαττωμένη', aug: 'αυξημένη',
  },
  en: {
    maj: 'major', min: 'minor', '7': 'dominant 7th', maj7: 'major 7th', m7: 'minor 7th',
    sus2: 'suspended 2nd', sus4: 'suspended 4th', dim: 'diminished', aug: 'augmented',
  },
}

export function pcOf(name: string): number {
  const pc = PC[name]
  if (pc === undefined) throw new Error(`unknown pitch name: ${name}`)
  return pc
}

export function pitchClassName(pc: number, lang: Lang): string {
  return NAMES[lang][((pc % 12) + 12) % 12]
}

export function noteName(midi: number, lang: Lang): string {
  return pitchClassName(midi, lang)
}

export function chordTones(root: string, quality: string): number[] {
  const intervals = QUALITY_INTERVALS[quality] ?? QUALITY_INTERVALS.maj
  const r = pcOf(root)
  return intervals.map((i) => (r + i) % 12)
}

export function chordLongName(root: string, quality: string, lang: Lang): string {
  return `${pitchClassName(pcOf(root), lang)} ${QUALITY_LONG[lang][quality] ?? quality}`
}

export function keyName(tonic: string, mode: 'major' | 'minor', lang: Lang): string {
  const word = lang === 'el' ? (mode === 'major' ? 'μείζονα' : 'ελάσσονα') : mode
  return `${pitchClassName(pcOf(tonic), lang)} ${word}`
}

export function fingeringFor(toneCount: number): string {
  return toneCount >= 4 ? '5 3 2 1' : '5 3 1'
}

`app/src/song/loader.ts`:

```ts
import type { Song, SongSummary } from './types'

export type SongLoadErrorCode = 'network' | 'not_found' | 'schema_mismatch'

export class SongLoadError extends Error {
  readonly code: SongLoadErrorCode

  constructor(code: SongLoadErrorCode) {
    super(code)
    this.name = 'SongLoadError'
    this.code = code
  }
}

type FetchLike = (url: string) => Promise<Response>

const REQUIRED = ['id', 'title', 'durationSec', 'sourceType', 'tempo', 'timeSignature', 'key', 'chords', 'arrangements']

const isObject = (v: unknown): v is Record<string, unknown> => typeof v === 'object' && v !== null && !Array.isArray(v)

export function parseSong(data: unknown): Song {
  if (!isObject(data) || data.schemaVersion !== 1) throw new SongLoadError('schema_mismatch')
  if (REQUIRED.some((k) => !(k in data))) throw new SongLoadError('schema_mismatch')
  if (!Array.isArray(data.chords) || !isObject(data.arrangements) || !isObject(data.tempo)) {
    throw new SongLoadError('schema_mismatch')
  }
  return { warnings: [], ...data } as unknown as Song
}

export function songUrl(id: string): string {
  return `/songs/${encodeURIComponent(id)}/song.json`
}

async function getJson(url: string, fetchImpl: FetchLike): Promise<unknown> {
  let res: Response
  try {
    res = await fetchImpl(url)
  } catch {
    throw new SongLoadError('network')
  }
  if (res.status === 404) throw new SongLoadError('not_found')
  if (!res.ok) throw new SongLoadError('network')
  try {
    return await res.json()
  } catch {
    throw new SongLoadError('schema_mismatch')
  }
}

export async function loadSong(id: string, fetchImpl: FetchLike = (u) => fetch(u)): Promise<Song> {
  return parseSong(await getJson(songUrl(id), fetchImpl))
}

export async function loadIndex(fetchImpl: FetchLike = (u) => fetch(u)): Promise<SongSummary[]> {
  const data = await getJson('/songs/index.json', fetchImpl)
  if (!Array.isArray(data)) throw new SongLoadError('schema_mismatch')
  return data as SongSummary[]
}

const WHITE_PCS = [0, 2, 4, 5, 7, 9, 11]
const pc = (p: number) => ((p % 12) + 12) % 12

export const isBlack = (p: number): boolean => !WHITE_PCS.includes(pc(p))

export interface KeyRect { pitch: number; black: boolean; x: number; w: number }
export interface KeyboardLayout { lo: number; hi: number; whites: KeyRect[]; blacks: KeyRect[]; byPitch: Map<number, KeyRect> }

export function keyboardRange(pitches: number[], minOctaves = 2): [number, number] {
  if (pitches.length === 0) return [48, 83]
  let lo = pitches.reduce((a, b) => Math.min(a, b))
  let hi = pitches.reduce((a, b) => Math.max(a, b))
  lo -= pc(lo)
  hi += 11 - pc(hi)
  while (hi - lo + 1 < minOctaves * 12) {
    if (lo - 12 >= 21) lo -= 12
    else hi += 12
  }
  return [Math.max(21, lo), Math.min(108, hi)]
}

export function layoutKeyboard(lo: number, hi: number, width: number): KeyboardLayout {
  const whitePitches: number[] = []
  for (let p = lo; p <= hi; p++) if (!isBlack(p)) whitePitches.push(p)
  const kw = width / Math.max(1, whitePitches.length)
  const bw = kw * 0.58
  const byPitch = new Map<number, KeyRect>()
  const whites = whitePitches.map((pitch, i) => {
    const key = { pitch, black: false, x: i * kw, w: kw }
    byPitch.set(pitch, key)
    return key
  })
  const blacks: KeyRect[] = []
  for (let p = lo; p <= hi; p++) {
    if (!isBlack(p)) continue
    const left = byPitch.get(p - 1)
    if (!left) continue
    const key = { pitch: p, black: true, x: left.x + kw - bw / 2, w: bw }
    byPitch.set(p, key)
    blacks.push(key)
  }
  return { lo, hi, whites, blacks, byPitch }
}

import type { KeyboardLayout } from './keyboard'

export interface NoteRect { pitch: number; hand: Hand; x: number; y: number; w: number; h: number; active: boolean; black: boolean }

export function visibleNoteRects(notes: Note[], layout: KeyboardLayout, now: number, lookahead: number, height: number): NoteRect[] {
  const pps = height / lookahead
  const out: NoteRect[] = []
  for (const n of notes) {
    if (n.end <= now || n.start >= now + lookahead) continue
    const key = layout.byPitch.get(n.pitch)
    if (!key) continue
    const bottom = Math.min(height, height - (n.start - now) * pps)
    const top = Math.max(0, height - (n.end - now) * pps)
    const pad = key.black ? 1 : 2
    out.push({
      pitch: n.pitch, hand: n.hand, black: key.black,
      x: key.x + pad, w: key.w - pad * 2, y: top, h: bottom - top,
      active: n.start <= now && now < n.end,
    })
  }
  return out
}

export function activeKeys(notes: Note[], now: number): Map<number, Hand> {
  const keys = new Map<number, Hand>()
  for (const n of notes) if (n.start <= now && now < n.end) keys.set(n.pitch, n.hand)
  return keys
}

import type { Loop } from './types'

export interface TransportState {
  position: number
  playing: boolean
  rate: number
  loop: Loop | null
  duration: number
}

const MIN_LOOP = 0.25

export function advance(s: TransportState, dt: number): TransportState {
  if (!s.playing || dt <= 0) return s
  const p = s.position + dt * s.rate
  if (s.loop && s.position < s.loop.b && p >= s.loop.b) {
    const len = s.loop.b - s.loop.a
    return { ...s, position: s.loop.a + ((p - s.loop.b) % len) }
  }
  if (p >= s.duration) return { ...s, position: s.duration, playing: false }
  return { ...s, position: p }
}

export interface PlaybackClock {
  now(): number
  isPlaying(): boolean
  rate(): number
  loop(): Loop | null
  play(): void
  pause(): void
  seek(t: number): void
  setRate(rate: number): void
  setLoop(loop: Loop | null): void
  subscribe(fn: () => void): () => void
}

export class TransportClock implements PlaybackClock {
  private state: TransportState
  private last: number
  private readonly timeSource: () => number
  private readonly listeners = new Set<() => void>()

  constructor(duration: number, timeSource: () => number = () => performance.now() / 1000) {
    this.timeSource = timeSource
    this.last = timeSource()
    this.state = { position: 0, playing: false, rate: 1, loop: null, duration }
  }

  now(): number {
    this.sync()
    return this.state.position
  }

  isPlaying(): boolean {
    return this.state.playing
  }

  rate(): number {
    return this.state.rate
  }

  loop(): Loop | null {
    return this.state.loop
  }

  play(): void {
    this.sync()
    const atEnd = this.state.position >= this.state.duration
    this.state = { ...this.state, playing: true, position: atEnd ? 0 : this.state.position }
    this.emit()
  }

  pause(): void {
    this.sync()
    this.state = { ...this.state, playing: false }
    this.emit()
  }

  seek(t: number): void {
    this.sync()
    this.state = { ...this.state, position: Math.min(this.state.duration, Math.max(0, t)) }
    this.emit()
  }

  setRate(rate: number): void {
    this.sync()
    this.state = { ...this.state, rate }
    this.emit()
  }

  setLoop(loop: Loop | null): void {
    this.sync()
    const valid = loop && loop.b - loop.a >= MIN_LOOP ? loop : null
    let position = this.state.position
    if (valid && (position < valid.a || position >= valid.b)) position = valid.a
    this.state = { ...this.state, loop: valid, position }
    this.emit()
  }

  subscribe(fn: () => void): () => void {
    this.listeners.add(fn)
    return () => {
      this.listeners.delete(fn)
    }
  }

  private sync(): void {
    const t = this.timeSource()
    const dt = t - this.last
    this.last = t
    const wasPlaying = this.state.playing
    this.state = advance(this.state, dt)
    if (wasPlaying && !this.state.playing) this.emit()
  }

  private emit(): void {
    for (const fn of this.listeners) fn()
  }
}
```

import type { Note } from '../song/types'
import type { PlaybackClock } from '../player/transport'
import type { Loop } from '../player/types'

export const AUDIO_LATENCY = 0.05
// The canvas draws this far behind the clock so notes hit the keyboard when they sound.
export const VISUAL_OFFSET = AUDIO_LATENCY

const SALAMANDER_BASE = 'https://tonejs.github.io/audio/salamander/'
const TONE_NAMES = ['C', 'C#', 'D', 'D#', 'E', 'F', 'F#', 'G', 'G#', 'A', 'A#', 'B']

export function crossedNotes(notes: Note[], prev: number, now: number, loop: Loop | null): Note[] {
  if (now >= prev) return notes.filter((n) => n.start >= prev && n.start < now)
  if (!loop) return []
  return notes.filter((n) => (n.start >= prev && n.start < loop.b) || (n.start >= loop.a && n.start < now))
}

export function midiToToneName(midi: number): string {
  return `${TONE_NAMES[((midi % 12) + 12) % 12]}${Math.floor(midi / 12) - 1}`
}

export function salamanderUrls(): Record<string, string> {
  const urls: Record<string, string> = { A0: 'A0.mp3', C8: 'C8.mp3' }
  for (let o = 1; o <= 7; o++) {
    urls[`C${o}`] = `C${o}.mp3`
    urls[`D#${o}`] = `Ds${o}.mp3`
    urls[`F#${o}`] = `Fs${o}.mp3`
    urls[`A${o}`] = `A${o}.mp3`
  }
  return urls
}

export interface SamplerLike {
  trigger(note: string, duration: number, time: number, velocity: number): void
  now(): number
  dispose(): void
}

export class PianoEngine {
  private prev = 0
  private timer: ReturnType<typeof setInterval> | null = null
  private unsubscribe: (() => void) | null = null
  private readonly clock: PlaybackClock
  private readonly sampler: SamplerLike
  private readonly getNotes: () => Note[]

  constructor(clock: PlaybackClock, sampler: SamplerLike, getNotes: () => Note[]) {
    this.clock = clock
    this.sampler = sampler
    this.getNotes = getNotes
  }

  start(): void {
    this.prev = this.clock.now()
    this.unsubscribe = this.clock.subscribe(() => {
      this.prev = this.clock.now()
    })
    this.timer = setInterval(() => this.tick(), 25)
  }

  stop(): void {
    if (this.timer) clearInterval(this.timer)
    this.timer = null
    this.unsubscribe?.()
    this.unsubscribe = null
    this.sampler.dispose()
  }

  tick(): void {
    const now = this.clock.now()
    if (!this.clock.isPlaying()) {
      this.prev = now
      return
    }
    const rate = this.clock.rate()
    const base = this.sampler.now()
    for (const n of crossedNotes(this.getNotes(), this.prev, now, this.clock.loop())) {
      const late = Math.max(0, now - n.start) / rate
      const duration = Math.max(0.05, (n.end - n.start) / rate)
      this.sampler.trigger(midiToToneName(n.pitch), duration, base + Math.max(0, AUDIO_LATENCY - late), n.velocity / 127)
    }
    this.prev = now
  }
}

type ToneModule = typeof import('tone')
let toneModule: ToneModule | null = null
let tonePromise: Promise<ToneModule> | null = null

export function preloadTone(): Promise<ToneModule> {
  tonePromise ??= import('tone').then((m) => (toneModule = m))
  return tonePromise
}

// Must run synchronously inside the click handler: iOS only unlocks audio within the user gesture.
export function unlockAudio(): void {
  void toneModule?.start()
}

export async function createSampler(): Promise<SamplerLike> {
  const Tone = await preloadTone()
  await Tone.start()
  const sampler = new Tone.Sampler({ urls: salamanderUrls(), baseUrl: SALAMANDER_BASE, release: 1 }).toDestination()
  await Tone.loaded()
  return {
    trigger: (note, duration, time, velocity) => sampler.triggerAttackRelease(note, duration, time, velocity),
    now: () => Tone.now(),
    dispose: () => sampler.dispose(),
  }
}

  const rollHeight = i.height - i.keyboardHeight
  const pps = rollHeight / i.lookahead
  const rects = visibleNoteRects(i.notes, i.layout, i.now, i.lookahead, rollHeight).map((r) => ({
    ...r,
    dim: !i.hands[r.hand],
    label: i.names && !r.black && r.h >= 16 ? noteName(r.pitch, i.lang) : '',
  }))
  const lit = new Map([...activeKeys(i.notes, i.now)].filter(([, hand]) => i.hands[hand]))
  return {
    width: i.width,
    height: i.height,
    rollHeight,
    keyboardHeight: i.keyboardHeight,
    whites: i.layout.whites,
    blacks: i.layout.blacks,
    lit,
    rects,
    beatLines: beatMarks(i.tempo, i.now, i.lookahead).map((b) => ({ y: rollHeight - (b.t - i.now) * pps, strong: b.strong })),
    lanes: i.layout.whites.filter((k) => k.pitch % 12 === 0 || k.pitch % 12 === 5).map((k) => k.x),
    cLabels: i.layout.whites.filter((k) => k.pitch % 12 === 0).map((k) => ({ x: k.x + k.w / 2, label: `C${Math.floor(k.pitch / 12) - 1}`, pitch: k.pitch })),
  }
}

const handColor = (h: Hand) => (h === 'L' ? THEME.left : THEME.right)
const handGlow = (h: Hand) => (h === 'L' ? THEME.leftGlow : THEME.rightGlow)

export function drawFrame(ctx: CanvasRenderingContext2D, f: Frame): void {
  const T = THEME
  ctx.clearRect(0, 0, f.width, f.height)
  ctx.globalAlpha = 1
  ctx.shadowBlur = 0
  ctx.fillStyle = T.roll
  ctx.fillRect(0, 0, f.width, f.rollHeight)
  ctx.fillStyle = T.lane
  for (const x of f.lanes) ctx.fillRect(x, 0, 1, f.rollHeight)
  for (const b of f.beatLines) {
    ctx.fillStyle = b.strong ? T.bar : T.beat
    ctx.fillRect(0, b.y, f.width, 1)
  }

  for (const r of f.rects) {
    const gradient = ctx.createLinearGradient(0, r.y, 0, r.y + r.h)
    gradient.addColorStop(0, r.hand === 'L' ? T.leftHi : T.rightHi)
    gradient.addColorStop(1, handColor(r.hand))
    const glow = r.active && !r.dim
    ctx.globalAlpha = r.dim ? 0.22 : 1
    ctx.shadowColor = glow ? handGlow(r.hand) : 'transparent'
    ctx.shadowBlur = glow ? 16 : 0
    ctx.fillStyle = gradient
    ctx.beginPath()
    ctx.roundRect(r.x, r.y, r.w, r.h, Math.min(6, r.w / 2, r.h / 2))
    ctx.fill()
    if (r.label) {
      ctx.shadowBlur = 0
      ctx.fillStyle = r.hand === 'L' ? T.leftInk : T.rightInk
      ctx.font = `700 9px ${T.fontBody}`
      ctx.textAlign = 'center'
      ctx.textBaseline = 'bottom'
      ctx.fillText(r.label, r.x + r.w / 2, r.y + r.h - 3)
    }
  }
  ctx.globalAlpha = 1

  ctx.shadowColor = T.hitGlow
  ctx.shadowBlur = 12
  ctx.fillStyle = T.hit
  ctx.fillRect(0, f.rollHeight - 2, f.width, 2)

  const top = f.rollHeight
  for (const k of f.whites) {
    const hand = f.lit.get(k.pitch)
    ctx.shadowColor = hand ? handGlow(hand) : 'transparent'
    ctx.shadowBlur = hand ? 22 : 0
    ctx.fillStyle = hand ? handColor(hand) : T.keyWhite
    ctx.beginPath()
    ctx.roundRect(k.x + 0.5, top, k.w - 1, f.keyboardHeight, [0, 0, 5, 5])
    ctx.fill()
  }
  ctx.shadowBlur = 0
  ctx.fillStyle = T.keyLabel
  ctx.font = `600 9px ${T.fontMono}`
  ctx.textAlign = 'center'
  ctx.textBaseline = 'bottom'
  for (const c of f.cLabels) if (!f.lit.has(c.pitch)) ctx.fillText(c.label, c.x, top + f.keyboardHeight - 5)

  const blackHeight = f.keyboardHeight * 0.62
  for (const k of f.blacks) {
    const hand = f.lit.get(k.pitch)
    ctx.shadowColor = hand ? handGlow(hand) : 'rgba(0,0,0,0.35)'
    ctx.shadowBlur = hand ? 18 : 3
    ctx.fillStyle = hand ? handColor(hand) : T.keyBlack
    ctx.beginPath()
    ctx.roundRect(k.x, top, k.w, blackHeight, [0, 0, 4, 4])
    ctx.fill()
  }
  ctx.shadowBlur = 0
}

import { useEffect, useRef } from 'react'
import { VISUAL_OFFSET } from '../audio/piano'
import type { Lang } from '../i18n/messages'
import type { Note, Tempo } from '../song/types'
import { layoutKeyboard } from './keyboard'
import { LOOKAHEAD_SEC, buildFrame, drawFrame } from './renderer'
import type { PlaybackClock } from './transport'

export interface RollView { hands: { L: boolean; R: boolean }; names: boolean; lang: Lang }

interface Props {
  clock: PlaybackClock
  tempo: Tempo
  notes: Note[]
  lo: number
  hi: number
  label: string
  getView: () => RollView
}

export function PianoRoll({ clock, tempo, notes, lo, hi, label, getView }: Props) {
  const canvasRef = useRef<HTMLCanvasElement>(null)
  const notesRef = useRef(notes)
  const viewRef = useRef(getView)
  notesRef.current = notes
  viewRef.current = getView

  useEffect(() => {
    const canvas = canvasRef.current
    const ctx = canvas?.getContext('2d')
    if (!canvas || !ctx) return
    let size = { w: 0, h: 0 }
    let layout = layoutKeyboard(lo, hi, 1)
    const resize = () => {
      const rect = canvas.getBoundingClientRect()
      const dpr = window.devicePixelRatio || 1
      canvas.width = Math.round(rect.width * dpr)
      canvas.height = Math.round(rect.height * dpr)
      ctx.setTransform(dpr, 0, 0, dpr, 0, 0)
      size = { w: rect.width, h: rect.height }
      layout = layoutKeyboard(lo, hi, rect.width)
    }
    const observer = new ResizeObserver(resize)
    observer.observe(canvas)
    resize()
    let raf = 0
    const frame = () => {
      const view = viewRef.current()
      const keyboardHeight = Math.min(96, Math.max(64, size.h * 0.3))
      drawFrame(ctx, buildFrame({
        notes: notesRef.current, layout, tempo, now: clock.now() - VISUAL_OFFSET, lookahead: LOOKAHEAD_SEC,
        width: size.w, height: size.h, keyboardHeight, hands: view.hands, names: view.names, lang: view.lang,
      }))
      raf = requestAnimationFrame(frame)
    }
    raf = requestAnimationFrame(frame)
    return () => {
      cancelAnimationFrame(raf)
      observer.disconnect()
    }
  }, [clock, tempo, lo, hi])

  return <canvas ref={canvasRef} className="roll-canvas" role="img" aria-label={label} />
}

export const SPEEDS = [0.25, 0.5, 0.75, 1]

interface PlayerState {
  level: Level
  hands: { L: boolean; R: boolean }
  speed: number
  loop: Loop | null
  names: boolean
  card: boolean
  reset: (levels: Level[]) => void
  setLevel: (level: Level) => void
  toggleHand: (hand: Hand) => void
  cycleSpeed: () => void
  setLoop: (loop: Loop | null) => void
  toggleNames: () => void
  toggleCard: () => void
}

export const usePlayer = create<PlayerState>((set, get) => ({
  level: 'medium',
  hands: { L: true, R: true },
  speed: 1,
  loop: null,
  names: false,
  card: true,
  reset: (levels) => set({ level: levels.includes('medium') ? 'medium' : (levels[0] ?? 'medium'), loop: null }),
  setLevel: (level) => set({ level }),
  toggleHand: (hand) => set({ hands: { ...get().hands, [hand]: !get().hands[hand] } }),
  cycleSpeed: () => set({ speed: SPEEDS[(SPEEDS.indexOf(get().speed) + 1) % SPEEDS.length] }),
  setLoop: (loop) => set({ loop }),
  toggleNames: () => set({ names: !get().names }),
  toggleCard: () => set({ card: !get().card }),
}))

import { useCallback, useEffect, useRef, useState, useSyncExternalStore, type RefObject } from 'react'
import { PianoEngine, createSampler, preloadTone, unlockAudio } from '../audio/piano'
import type { Note } from '../song/types'
import type { PlaybackClock } from './transport'

export function useClockTime(clock: PlaybackClock, intervalMs = 100): number {
  const [t, setT] = useState(() => clock.now())
  useEffect(() => {
    const id = setInterval(() => setT(clock.now()), intervalMs)
    const off = clock.subscribe(() => setT(clock.now()))
    return () => {
      clearInterval(id)
      off()
    }
  }, [clock, intervalMs])
  return t
}

export function useClockPlaying(clock: PlaybackClock): boolean {
  return useSyncExternalStore(
    (onChange) => clock.subscribe(onChange),
    () => clock.isPlaying(),
  )
}

export function useWakeLock(active: boolean): void {
  useEffect(() => {
    if (!active || !('wakeLock' in navigator)) return
    let lock: WakeLockSentinel | null = null
    let cancelled = false
    navigator.wakeLock.request('screen').then(
      (l) => {
        if (cancelled) void l.release()
        else lock = l
      },
      () => {},
    )
    return () => {
      cancelled = true
      void lock?.release()
    }
  }, [active])
}

export type PianoStatus = 'idle' | 'loading' | 'ready' | 'failed'

export function usePiano(clock: PlaybackClock, notesRef: RefObject<Note[]>) {
  const engine = useRef<PianoEngine | null>(null)
  const started = useRef(false)
  const [status, setStatus] = useState<PianoStatus>('idle')

  useEffect(() => {
    preloadTone().catch(() => {})
  }, [])

  const ensure = useCallback(async () => {
    unlockAudio()
    if (started.current) return
    started.current = true
    setStatus('loading')
    try {
      const sampler = await createSampler()
      engine.current = new PianoEngine(clock, sampler, () => notesRef.current ?? [])
      engine.current.start()
      setStatus('ready')
    } catch {
      setStatus('failed')
    }
  }, [clock, notesRef])

  useEffect(
    () => () => {
      engine.current?.stop()
      engine.current = null
      started.current = false
    },
    [clock],
  )

  return { status, ensure }
}

import type { Loop } from './types'

interface TimelineProps {
  position: number
  duration: number
  loop: Loop | null
  label: string
  onSeek: (t: number) => void
  onLoop: (loop: Loop) => void
}

function Timeline({ position, duration, loop, label, onSeek, onLoop }: TimelineProps) {
  const ref = useRef<HTMLDivElement>(null)
  const drag = useRef<{ x0: number; t0: number; moved: boolean } | null>(null)
  const [preview, setPreview] = useState<Loop | null>(null)
  const timeAt = (clientX: number) => {
    const r = ref.current?.getBoundingClientRect()
    return r ? xToTime(clientX - r.left, r.width, duration) : 0
  }
  const pct = (t: number) => `${(duration > 0 ? t / duration : 0) * 100}%`
  const shown = preview ?? loop

  const onPointerDown = (e: PointerEvent<HTMLDivElement>) => {
    e.currentTarget.setPointerCapture?.(e.pointerId)
    drag.current = { x0: e.clientX, t0: timeAt(e.clientX), moved: false }
  }
  const onPointerMove = (e: PointerEvent<HTMLDivElement>) => {
    const d = drag.current
    if (!d) return
    if (Math.abs(e.clientX - d.x0) > 8) d.moved = true
    if (d.moved) {
      const t = timeAt(e.clientX)
      setPreview({ a: Math.min(d.t0, t), b: Math.max(d.t0, t) })
    }
  }
  const onPointerUp = (e: PointerEvent<HTMLDivElement>) => {
    const d = drag.current
    drag.current = null
    if (d?.moved && preview) onLoop(preview)
    else if (d) onSeek(timeAt(e.clientX))
    setPreview(null)
  }
  const onKeyDown = (e: KeyboardEvent<HTMLDivElement>) => {
    if (e.key === 'ArrowLeft') onSeek(position - 5)
    if (e.key === 'ArrowRight') onSeek(position + 5)
  }

  return (
    <div
      ref={ref}
      className="timeline"
      role="slider"
      tabIndex={0}
      aria-label={label}
      aria-valuemin={0}
      aria-valuemax={Math.round(duration)}
      aria-valuenow={Math.round(position)}
      aria-valuetext={formatTime(position)}
      onPointerDown={onPointerDown}
      onPointerMove={onPointerMove}
      onPointerUp={onPointerUp}
      onKeyDown={onKeyDown}
    >
      <div className="track">
        {shown && (
          <>
            <div className="loop-region" style={{ left: pct(shown.a), width: pct(shown.b - shown.a) }} />
            <span className="loop-mark" style={{ left: pct(shown.a) }}>A</span>
            <span className="loop-mark" style={{ left: pct(shown.b) }}>B</span>
          </>
        )}
        <div className="progress" style={{ width: pct(position) }} />
        <div className="thumb" style={{ left: pct(position) }} />
      </div>
    </div>
  )
}

interface Props { clock: PlaybackClock; duration: number; playing: boolean; onTogglePlay: () => void }

export function Controls({ clock, duration, playing, onTogglePlay }: Props) {

function Player({ song }: { song: Song }) {
  const m = useMessages()
  const clock = useMemo(() => new TransportClock(song.durationSec), [song])
  const levels = useMemo(() => availableLevels(song), [song])
  useEffect(() => usePlayer.getState().reset(levels), [levels])

  const notes = song.arrangements[level]?.notes ?? []
  const notesRef = useRef(notes)
  notesRef.current = notes

  const [lo, hi] = useMemo(
    () => keyboardRange(Object.values(song.arrangements).flatMap((a) => a?.notes.map((n) => n.pitch) ?? [])),
    [song],
  )
  useEffect(() => clock.setRate(speed), [clock, speed])
  useEffect(() => clock.setLoop(loop), [clock, loop])

  const playing = useClockPlaying(clock)
  const piano = usePiano(clock, notesRef)
  useWakeLock(playing)

  const togglePlay = () => {
    void piano.ensure()
    if (clock.isPlaying()) clock.pause()
    else clock.play()
  }
  const getView = useCallback(() => {
    const { hands, names } = usePlayer.getState()
    return { hands, names, lang: useLang.getState().lang }
  }, [])

  return (
    <div className="player">
      <TopBar song={song} levels={levels} />
      <ChordLane clock={clock} chords={song.chords} />
      <div className="stage">
        <PianoRoll clock={clock} tempo={song.tempo} notes={notes} lo={lo} hi={hi} label={m.player.rollLabel} getView={getView} />
        {card && <ChordCard clock={clock} chords={song.chords} />}
      </div>
      <Controls clock={clock} duration={song.durationSec} playing={playing} onTogglePlay={togglePlay} />

    </div>
  )
}

export function PlayerScreen() {

      </div>
    )
  }
  if (!state.song) return <div className="player-message" role="status">{m.player.loading}</div>
  return <Player song={state.song} />

import { expect, test } from '@playwright/test'

test('library → player → play, level, speed → back → language', async ({ page }) => {

  await page.route('https://tonejs.github.io/**', (route) => route.abort())
  await page.addInitScript(() => localStorage.setItem('pianoverse.lang', 'el'))

  await expect(page.getByRole('img', { name: 'Νότες που πέφτουν προς το πληκτρολόγιο' })).toBeVisible()

  await expect(page.getByRole('button', { name: 'Παύση' })).toBeVisible()

  await expect(page.getByRole('button', { name: 'Εύκολο' })).toHaveAttribute('aria-pressed', 'true')

# Pianoverse app

Library and landscape player for engine `song.json` files. Design: `docs/superpowers/specs/2026-11-07-pianoverse-design.md` (§5, §6, §6.1).

pnpm install

## Your own songs

Run the engine (`engine/README.md`), then copy its `song.json` to `public/songs/<id>/song.json` and add an entry to `public/songs/index.json` (`id`, `title`, `key`, `bpm`, `durationSec`, `sourceType`, `chords`). Don't commit songs you don't own.

## Test

```bash
pnpm test          # unit + component tests
pnpm test:e2e  # browser smoke test (first: pnpm exec playwright install chromium)
```

The piano sound loads from the Tone.js Salamander samples (network); without it the player keeps running silently.
