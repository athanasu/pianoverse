# Pianoverse app

Library and landscape player for engine `song.json` files. Design: `docs/superpowers/specs/2026-11-07-pianoverse-design.md` (§5, §6, §6.1).

## Run

Needs Node 22.22 or newer and pnpm.

```bash
pnpm install
pnpm dev
```

Open the printed URL. The demo song (`public/songs/demo`) is generated by `pnpm make:demo`.

`pnpm build` writes a static site to `dist/`. Static hosting needs an SPA fallback (serve `index.html` for unknown paths), otherwise opening or reloading `/song/:id` directly returns a 404.

## Your own songs

Run the engine (`engine/README.md`), then copy its `song.json` to `public/songs/<id>/song.json` and add an entry to `public/songs/index.json` (`id`, `title`, `key`, `bpm`, `durationSec`, `sourceType`, `chords`). Don't commit songs you don't own.

## Test

```bash
pnpm test      # unit + component tests
pnpm test:e2e  # browser smoke test (first: pnpm exec playwright install chromium)
```

The piano sound loads from the Tone.js Salamander samples (network); without it the player keeps running silently.
